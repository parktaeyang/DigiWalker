# DigiWalker

Apple Watch에서 컬러 도트 몬스터를 키우는 걸음 기반 육성 게임입니다 (iOS + watchOS).
디지타마로 시작해 누적 500걸음을 채우면 유년기 디지몬 한 마리가 부화합니다.
워치에서 HealthKit 걸음 수를 정산해 걸음으로만 키우고(레벨·경험치 없음), 궁극체 뒤 85,000걸음에 새 알을 다시 키울 수 있습니다. iPhone에서는 마지막으로 받은 파트너 기록을 확인하고 새 알 요청을 보냅니다.

- 구현 및 검증 현황은 [개발 기록](docs/PROGRESS.md)에 정리합니다.
- 설계 원본과 개발 기준은 [프로젝트 규칙](AGENTS.md)을 따릅니다.
- 개발자 본인 기기에서 사용하는 비공개·비상업 프로토타입입니다.
