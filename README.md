# DigiWalker

Apple Watch에서 컬러 도트 몬스터를 키우는 걸음 기반 육성 게임입니다 (iOS + watchOS).
실제 걸음 수(HealthKit)를 경험치로 바꾸고, 몬스터는 레벨이 오르면 진화합니다.

- 상태: 설계 단계 (MVP 구현 전)
- 설계서: [docs/DESIGN.md](docs/DESIGN.md)
- 배포 범위: 개발자 본인 기기 전용, 비공개·비상업

## 에셋 정책

이 저장소에는 직접 만든 오리지널 몬스터(`Assets/StarterPack/`)만 커밋합니다.
개인용 에셋 팩은 `PrivateAssets/`에 두며 git에 포함하지 않습니다 (설계서 §14).
